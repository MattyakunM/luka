# Luka v2.0

ブラウザで動く、Discord × LINE系を目指したオリジナルコミュニケーションツール。

## v2.0
- 招待制スペース
- 一般ユーザーは参加済み/自分のスペースのみ表示
- 管理者は全スペースを表示・管理
- スペース削除は設定画面から確認付き
- 部屋作成・削除
- リアルタイムチャット
- メッセージ編集・削除
- ファイルアップロード
- 通報→管理者通知データ→管理画面
- Render/GitHub向けのシンプルな構成

## 起動
npm install
npm start

## Render
Build Command: npm install
Start Command: npm start

## 重要
現段階ではJSON保存とローカルファイル保存。Renderの無料環境では再起動/再デプロイ時に永続保存されない場合があります。
AI開発アシスタントはOpenAI API等をバックエンドから接続する設計にし、APIキーをブラウザへ出さないでください。
