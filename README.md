# Luka V4 完全ローカル版

サーバー不要でブラウザだけで動く、サーバー化前の統合テスト版です。

## 起動
`index.html` をブラウザで開くだけ。

## 統合済み
- 通常ホーム / 管理者画面
- 「そら」唯一の管理者
- 通常アカウント作成 / 管理者から通常アカウント作成 / 切替
- 通常アカウントは1ブラウザにつき1つ
- 友達・ユーザー検索
- DM
- Luka公式 / Luka Update / Luka管理者
- Luka公式の簡易自動返信
- スペース / ルーム作成
- メッセージ
- 複数絵文字リアクション＋人数
- 返信 / 編集 / 削除 / ピン
- メッセージ検索
- 通知
- 通報
- 管理者ダッシュボード
- 全スペース・ルームの管理者閲覧
- ユーザー利用停止
- 通話UI
- 設定
- ローカルバックアップ書き出し / 読み込み

## 注意
データはブラウザのlocalStorageに保存され、別端末とは共有されません。
実際のサーバー認証、複数端末同期、強制的な端末BAN、永続ファイル保存、実WebRTC通話などはサーバー版で実装します。
