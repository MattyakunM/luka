# Luka V4 完全ローカル修正版

## 使い方
`index.html` をブラウザで開いてください。

この版はサーバーやDBを使わず、ブラウザのlocalStorageだけで動作します。

## 入っているもの
- そら固定の管理者アカウント
- 通常アカウント作成・切替
- ホーム / プロフィール / ユーザー検索
- フレンド申請・承認
- DM
- Luka公式の自動返信
- Luka Update / Luka管理者
- スペース / ルーム
- メッセージ
- 絵文字リアクション
- 返信
- 編集 / 削除
- ピン
- 通知
- 通報
- 管理者ダッシュボード
- 全スペース・ルームの管理者閲覧
- ユーザー停止 / 再開
- バックアップ書き出し / 復元
- 設定
- レスポンシブ表示

## 注意
- 複数端末で同期する版ではありません。
- Luka公式はローカルの簡易自動応答です。本物の生成AI APIには未接続です。
- 通話は今回のローカル版の次段階でWebRTCサーバー接続を追加できます。
- ブラウザのlocalStorageを消すと、そのブラウザ内のデータは消えます。バックアップを使ってください。

## 次段階
このローカル版で画面・操作を固めたあと、PostgreSQL/Supabase等のDB、認証、永続ファイル保存、WebRTC/TURNをサーバー側に移します。
