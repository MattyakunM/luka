# Luka V4 完成補完版

これは、元の **Luka V4 サーバーレス版** に不足していた実用機能を補完した更新パッケージです。

## このZIPの使い方

1. GitHubで **mainではなく、V4を置いているブランチ/フォルダ**を開く。
2. このZIPを展開する。
3. 展開したフォルダの中にあるファイルを、V4プロジェクトのルートへコピーする。
4. **既存のユーザーデータ用JSONや独自データファイルは上書きしない。**
5. ブラウザを強制更新して動作確認する。

### 重要
このZIPは **現在Renderで動いているmainを直接置き換えるためのZIPではありません。**
V4のブラウザ版を完成させるための補完版です。

## 補完したもの

- V4状態の永続保存用ストレージ領域
- 設定値の保存
- 下書き/未読/ブロック/ピン/リアクション用の保存領域
- JSONバックアップの書き出し
- JSONバックアップの読み込みAPI
- キーボードからのバックアップ
- APIがない状態でも動かせるためのクライアント側基盤
- V4完成状態の診断フラグ

## データについて

このパッケージには既存ユーザーを消すための `luka.json` は入れていません。
既存データを守るため、データファイルはそのまま残してください。

## 次の段階

V4のUI/機能を固めた後、

**V4完成版 → サーバー化 → DB化 → Render等へ接続**

の順番で進めれば、現在のサイトへ安全に統合できます。
