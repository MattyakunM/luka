# Luka Web v3.1

v3.0のWeb基盤から、ユーザー同士の交流機能を大幅に追加した版。

## 追加
- プロフィール編集
- ユーザー検索
- フレンド申請 / 承認 / 拒否
- フレンド一覧
- ブロック基礎
- 1対1 DM
- DM履歴 / リアルタイムイベント
- 通知一覧 / 一括既読
- PC / iPad / スマホ向けUI
- 既存JSONに新しい配列を自動追加して旧データを壊しにくくする設計

## 注意
まだ本番完成版ではありません。JSON保存からPostgreSQL/Supabaseへの移行、ファイルストレージ、リアクション、ピン、検索、管理UI、公式AI、WebRTC、セキュリティ強化を次段階で行います。
