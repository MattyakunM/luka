# Luka v3.9 — Server Prep

Lukaを「本格サーバー＋DB」に移行する直前の準備版です。

## この版でやること
- DBの正式設計
- ユーザー/スペース/ルーム/メッセージ/DM/通知/通報/ファイル/リアクション/ピンをDB化するためのschema.sql
- 旧 `luka.json` からDBへ移すためのmigration準備
- APIをDB接続へ差し替えやすい構成
- 環境変数の整理
- 管理者/AIアカウントの役割定義
- 管理者には通常ユーザーのオンライン/入力中情報を見せない設計方針
- ファイルストレージを将来外部ストレージへ切り替えられる構成
- WebRTC通話のシグナリングを追加しやすい準備

## まだやらないこと
- 本番DBへの接続
- Supabase等へのアカウント作成
- TURN/SFUサーバーの構築
- 外部ファイルストレージの本番接続

つまり今回は「サーバーを作る一歩手前まで」です。

## 重要
既存の `luka.json` はこのZIPに含めていません。
現在のデータを保存したまま、次のDB移行工程へ進めるためです。

## 次工程
1. Supabase/PostgreSQL等のDBを用意
2. schema.sqlを適用
3. migration.jsで既存データを移行
4. DB接続用の環境変数をRender等に設定
5. DB版APIへ切り替え
6. バックアップ/セキュリティ確認
7. 通話用シグナリング/TURN等を接続
