# Luka v4.0 Local Complete

サーバー接続前の「Luka完成版・ローカル動作版」です。

## 目的
画面と操作を一つのLukaとして整理し、次の段階でAPI/DB/リアルタイムサーバーへ接続しやすくする。

## 含まれる機能
- ホーム
- プロフィール
- ユーザー検索
- 友達・友達申請
- DM
- スペース/ルーム
- メッセージ
- 編集/削除
- リアクション
- ピン留め
- 返信
- メッセージ検索
- ファイル/画像のUI
- 通知
- 通報
- 管理者ダッシュボード
- 全スペース/ルーム確認
- ユーザー管理
- Luka公式
- Luka Update
- Luka管理者
- 通話画面UI
- ビデオ/画面共有UI
- レスポンシブUI

## 起動
index.htmlをブラウザで開いてください。
Node.js等は不要です。

## 注意
これはサーバーなし版です。
データはブラウザのlocalStorageに保存されます。
別端末とは同期しません。

次の工程でこのUI/データ構造をAPI・DB・WebSocket・WebRTCへ接続します。
