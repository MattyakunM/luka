# Luka v1.6

ブラウザで動く「スペース＋部屋＋DM」型のリアルタイムコミュニケーションツールです。

## v1.6で入ったもの
- アカウント作成 / ログイン
- プロフィール
- スペース作成
- 部屋作成 / 切り替え
- リアルタイム部屋チャット
- メッセージ履歴の保存
- リアクション
- ユーザー検索
- フレンド申請 / 承認 / 拒否
- 1対1 DM
- オンライン / オフライン表示
- PC / タブレット / スマホ向けレスポンシブUI
- Socket.IOによるリアルタイム通信

## 起動
Node.jsを入れた環境で:

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## 公開
ReplitなどNode.jsサーバーを動かせるホスティングに、このフォルダをアップロードして `npm start` を実行してください。
静的サイト専用のGitHub PagesだけではSocket.IOサーバーを動かせないため、この版はそのままでは公開できません。

## 重要
これは学習・試作版です。一般公開する前に、bcrypt/Argon2等の強いパスワードハッシュ、HTTPS、レート制限、権限管理、入力検証、CSRF対策、DB、バックアップ、ファイルアップロードの安全対策などを追加してください。
