# Luka V10 working build
The package contains the official landing page from V10, a functional `/app` browser UI, local profile/space/message persistence, Community Hub and Bot Center UI, the existing V9 Supabase-ready server, and a Windows Electron wrapper source.
The Windows `.exe` itself must be built and then hosted as a release artifact; this source package does not pretend an installer exists when it has not been built.
