# Luka V8 — Account / Friends / DM

Based on V7. Adds functional server APIs for account creation/search, friend requests/accept/reject, DM channel creation/listing, DM history, and realtime Socket.IO events. Existing V6.2/V7 systems are retained.

This remains a development build: production authentication, password/session security, database migration, rate limiting, abuse controls, and hardened authorization still need to be completed before public release.
